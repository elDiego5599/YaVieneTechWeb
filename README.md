# Ya Viene Tech — Web

Sitio web de **Ya Viene Tech**, empresa de soluciones informáticas.

## Contexto

- `yaviene.yavienetech.com` presenta **Ya Viene**, la app para ver en el mapa dónde viene tu bus y recibir un aviso cuando esté cerca (Barranquilla, piloto con Sobusa).
- Este repositorio construye la **marca corporativa Ya Viene Tech**: la empresa detrás de Ya Viene y de futuras soluciones de software.

## Objetivos

- Identidad de marca Ya Viene Tech (logo, colores, tipografía, tono) coherente con la app Ya Viene.
- Presentar los servicios de soluciones informáticas.
- Mostrar Ya Viene como producto insignia.
- Canal de contacto para empresas.
